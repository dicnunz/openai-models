# OpenAI Models

An interactive comparison of publicly documented OpenAI language-model families from GPT-1 through GPT-6 Astra, organized by lineage, release chronology, capabilities, and public role.

## Run

No installation or build step is required. Download or clone the repository, then open `index.html` in a modern browser.

## Use

Search or filter the lineage, then click models to compare up to four at once. The capability table distinguishes documented and partial capabilities, and each selected model links to a primary source.

## Scope

Includes publicly documented OpenAI generative language-model families and materially distinct public variants. Dated API snapshots and simple aliases are collapsed into their families. Embedding, moderation, image/video-only, transcription-only, and TTS-only models are excluded.

Unknown technical details remain unknown. The comparison reflects the public record through September 10, 2026. It is an independent research visualization and is not affiliated with or endorsed by OpenAI.

## Implementation

The project is one self-contained HTML file. Data, layout, styling, and interaction live in `index.html`; there are no dependencies, backend services, or build tools.
